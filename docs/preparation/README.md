# Voorbereidende documenten (preparation)

Versie: 0.1

Voorbereidende **PoC-startnotities** voor de overgang naar alpha, beta en
productie: ze leggen vast wat nog geregeld moet worden, maar zijn nog niet
formeel vastgesteld. Dit gaat over het opgeleverde *product* — niet over AI als
ontwikkelgereedschap (dat staat in [`../ai-verantwoording.md`](../ai-verantwoording.md)).

| Document | Onderwerp |
|---|---|
| [`iama.md`](iama.md) | IAMA-startnotitie (grondrechten) — systeembreed |
| [`ai-verordening.md`](ai-verordening.md) | EU AI-verordening + Algoritmeregister — systeembreed |
| [`kvk-gegevens.md`](kvk-gegevens.md) | Voorbereiding KvK-gegevens van ondernemers — per databron |

**Per databron een eigen check.** Elke externe bron met (mogelijk)
persoonsgegevens krijgt vóór ingebruikname een eigen AVG/DPIA-toets en
grondslag-beoordeling. `kvk-gegevens.md` is het eerste voorbeeld; toekomstige
bronnen (bv. energiemaatschappijen) krijgen elk een eigen `<bron>-gegevens.md`.
De koppelroute — directe API of via een wallet (NL Wallet / Europese Business
Wallet) — is per bron **nog te besluiten** en bepaalt de DPIA.
